# About

**korynbid** is an open source project: a small, fast website for sharing study notes and articles, built from plain Markdown files.

## How it works

- Articles are written in Markdown.
- Every article is filed under a category. The home page lists all articles grouped by category and has a live search by title and category.
- Articles that belong to a series share a `[TAG]` in their title and link to each other with previous and next buttons.
- The site is fully static and hosted on GitHub Pages.

## Sources and credit

Each article shows its original author where known. If you notice a mistake or a copyright issue, please contact [lebroskiofficial@proton.me](mailto:lebroskiofficial@proton.me) and it will be fixed or removed.

## Comments and visit counts

Comments are powered by Giscus and stored in GitHub Discussions, so you need a GitHub account to comment. Visits are counted with GoatCounter, a privacy-friendly analytics service.

## Source code

The whole site is public at [github.com/korynbid/korynbid.github.io](https://github.com/korynbid/korynbid.github.io). Found a bug or have a suggestion? Open an issue or start a discussion there.
