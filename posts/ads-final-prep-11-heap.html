[ADS-FINAL-PREP] 11. Heap

Oct 24, 2026 · Algorithms & Data Structures · Author: Archiveskk · Source: https://t.me/c/2310214877/1713/1733

Description

A Heap is a tree-based data structure that implements a priority queue. The key characteristic of a heap is maintaining the heap property, which guarantees that every parent node satisfies a specific ordering relationship with respect to its child nodes.

There are two primary types of heaps:

  • Max-Heap: The parent node is always greater than or equal to its children.
  • Min-Heap: The parent node is always less than or equal to its children.

A heap is represented as a complete (or nearly complete) binary tree, where each node has at most two children. Because the tree is always balanced, insertion and extraction operations can be executed efficiently.

Types of Heaps

  • Max-Heap: In a max-heap, the value of each parent node is always greater than or equal to the values of its children. Consequently, the maximum element is always located at the root (top) of the heap.
  • Min-Heap: In a min-heap, the value of each parent node is always less than or equal to the values of its children. Thus, the minimum element is always located at the root of the heap.

Heap Operations

  1. Insert:
  2. An element is added to the end of the heap (maintaining the complete binary tree structure) and then "bubbled up" (heapify-up) to restore the heap property.
  1. Extract-Max / Extract-Min:
  2. Max-Heap: The root node containing the maximum value is extracted. It is replaced by the last element in the heap, followed by a "sift down" (heapify-down) operation to restore heap ordering.
  3. Min-Heap: The root node with the minimum value is extracted, followed by the same re-balancing procedure.
  1. Peek:
  2. An operation that retrieves the value of the root node without removing it.

Algorithms Based on Heaps

  • Heap Sort: Used to sort elements using a max-heap or min-heap. The algorithm builds a heap and iteratively extracts the maximum or minimum elements to form a sorted array.
  • Dijkstra's Algorithm: Used to find the shortest path in a weighted graph by repeatedly extracting the vertex with the minimum distance.
  • Huffman Coding: Used in data compression algorithms for optimal prefix coding, where min-heaps build the optimal encoding tree.

Primary Operation Complexities

  • Insert: O(log n)
  • Extract (Extract-Max / Extract-Min): O(log n)
  • Peek (Root view): O(1)
  • Build-Heap (from an unsorted array): O(n) using the bottom-up construction approach.

Heap Implementation

A heap can be efficiently stored using a standard array where parent-child relationships are calculated via zero-based index formulas:

  • Parent index: parent(i) = ⌊(i - 1) / 2⌋
  • Left child index: left(i) = 2i + 1
  • Right child index: right(i) = 2i + 2

Advantages

  • Efficiency: Logarithmic time complexity O(log n) for insertions and extractions makes heaps optimal for priority queue implementations.
  • Simplicity: Array-based tree representation eliminates pointer storage overhead and keeps algorithms straightforward to implement.

Disadvantages

  • Partial Ordering: A heap only guarantees strict order for the root element relative to its descendants, not a fully sorted dataset.
  • Full Sorting Overhead: Obtaining a completely sorted sequence requires repeated extractions, taking O(n log n) time (e.g., via Heap Sort).
class MinHeap:
    def __init__(self):
        self.heap = []

    def insert(self, value):
        self.heap.append(value)
        self._heapify_up(len(self.heap) - 1)

    def extract_min(self):
        if len(self.heap) == 0:
            raise IndexError("extract_min from an empty heap")
        min_value = self.heap[0]
        self.heap[0] = self.heap[-1]
        self.heap.pop()
        self._heapify_down(0)
        return min_value

    def peek(self):
        if len(self.heap) == 0:
            raise IndexError("peek from an empty heap")
        return self.heap[0]

    def _heapify_up(self, index):
        while index > 0:
            parent_index = (index - 1) // 2
            if self.heap[index] < self.heap[parent_index]:
                self.heap[index], self.heap[parent_index] = self.heap[parent_index], self.heap[index]
                index = parent_index
            else:
                break

    def _heapify_down(self, index):
        while 2 * index + 1 < len(self.heap):
            left_child_index = 2 * index + 1
            right_child_index = 2 * index + 2
            smallest = index

            if left_child_index < len(self.heap) and self.heap[left_child_index] < self.heap[smallest]:
                smallest = left_child_index
            if right_child_index < len(self.heap) and self.heap[right_child_index] < self.heap[smallest]:
                smallest = right_child_index
            if smallest != index:
                self.heap[index], self.heap[smallest] = self.heap[smallest], self.heap[index]
                index = smallest
            else:
                break
