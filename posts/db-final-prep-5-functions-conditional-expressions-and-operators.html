[DB-FINAL-PREP] 5. Functions, Conditional Expressions and Operators

Oct 25, 2026 · Databases · Author: Algo-holics · Source: https://t.me/kbtukbtu/372/640

Description

PostgreSQL ships with a large library of built-in functions and operators. This lecture covers three groups: mathematical functions, string functions and conditional expressions.

Part II: String Functions and Operators

SELECT FORMAT('Hello, %s!', 'PostgreSQL');          -- Hello, PostgreSQL!
SELECT UPPER('database'), INITCAP('hello world');   -- DATABASE, Hello World
SELECT LEFT('PostgreSQL', 4), RIGHT('PostgreSQL', 3); -- Post, SQL
SELECT POSITION('SQL' IN 'PostgreSQL');             -- 8
SELECT REPLACE('2024-01-15', '-', '/');             -- 2024/01/15
SELECT SUBSTRING('PostgreSQL', 1, 4);               -- Post
SELECT BTRIM('  padded  ');                         -- padded

Part III: Conditional Expressions

Conditional expressions run different logic depending on conditions. The most used are CASE, COALESCE, NULLIF, GREATEST and LEAST.

CASE

A generic conditional expression, similar to if/else in programming languages.

SELECT title,
       CASE
           WHEN rental_rate < 1 THEN 'Cheap'
           WHEN rental_rate < 3 THEN 'Standard'
           ELSE 'Premium'
       END AS price_category
FROM film;

COALESCE

Returns the first non-NULL argument. NULL is returned only if all arguments are NULL.

SELECT COALESCE(phone, email, 'no contact') FROM customer;

NULLIF

Returns NULL if value1 = value2; otherwise returns value1. This is the inverse of the COALESCE pattern and is useful for avoiding division by zero.

SELECT total / NULLIF(count, 0) FROM stats;

GREATEST and LEAST

Select the largest or smallest value from a list of any number of expressions.

SELECT GREATEST(1, 5, 3), LEAST(1, 5, 3);   -- 5, 1

Conclusion

Built-in math, string and conditional tools let you compute, reformat and branch inside a query without any application code.
