1. Complexity and Memory

Oct 23, 2026 · ADS-FINAL-PREP · Algorithms & Data Structures · Author: Archiveskk · Source: https://t.me/c/2310214877/1713/1733

Analyzing complexity and memory usage is the foundation of developing efficient algorithms. This section is dedicated to understanding and evaluating the execution time of algorithms and their impact on memory consumption.

Time Complexity

Time complexity describes how the execution time of an algorithm changes as the input size increases. It is measured in terms of Big O notation (asymptotic complexity).

Main Categories of Time Complexity:

  1. O(1) – Constant Complexity
  2. Execution time does not depend on the size of the input data.
  3. Example: Accessing an array element by index.
  1. O(log n) – Logarithmic Complexity
  2. The algorithm reduces the volume of data by half at each step.
  3. Example: Binary search.
  1. O(n) – Linear Complexity
  2. The algorithm iterates through all elements.
  3. Example: Finding the maximum value in an array.
  1. O(n log n) – Quasilinear Complexity
  2. Commonly found in sorting algorithms.
  3. Example: Quick Sort, Merge Sort.
  1. O(n²) – Quadratic Complexity
  2. Typical for algorithms that use nested loops.
  3. Example: Bubble Sort, checking all pairs of elements.
  1. O(2ⁿ) – Exponential Complexity
  2. Execution time doubles with each additional input element.
  3. Example: Solving problems by brute-forcing all combinations (e.g., the Knapsack Problem).
  1. O(n!) – Factorial Complexity
  2. Algorithms that iterate through all possible permutations.
  3. Example: The Travelling Salesperson Problem (in its simplest brute-force approach).

Why Is This Important?

  • Optimization: Complexity allows you to choose the best algorithm for a task, especially when dealing with large datasets.
  • Comparison: For example, Bubble Sort O(n²) is far less efficient than Merge Sort O(n log n).
  • Real-world Applications: Algorithms for large databases, web services, and machine learning depend heavily on time and space complexity.
