5. Linear Second-Order Equations

Oct 26, 2026 · DIFFEQ-FINAL-PREP · Differential Equations · Author: Archiveskk · Source: https://t.me/c/2310214877/1867/4793

Description

The general linear second-order equation is

P₀(x)y″ + P₁(x)y′ + P₂(x)y = F(x).

Because the equation is linear, solutions combine well, and the whole theory is built on that.

5.1 Homogeneous Equations: Theory

  • If y₁, y₂ solve the homogeneous equation, so does c₁y₁ + c₂y₂.
  • Two solutions form a fundamental set iff their Wronskian is nonzero:

``text W(y₁,y₂) = y₁y₂′ − y₁′y₂ ≠ 0. ``

  • The general solution is y = c₁y₁ + c₂y₂.
  • Nonhomogeneous equations: y = yₕ + yₚ, where yₕ is the general solution of the homogeneous equation and yₚ is any one particular solution.

5.2 Constant-Coefficient Homogeneous Equations

For ay″ + by′ + cy = 0 use y = eʳˣ and solve ar² + br + c = 0.

RootsGeneral solution
Distinct real r₁ ≠ r₂c₁e^(r₁x) + c₂e^(r₂x)
Double real reʳˣ(c₁ + c₂x)
Complex α ± iβe^(αx)(c₁ cos βx + c₂ sin βx)

5.3–5.5 Undetermined Coefficients

For ay″ + by′ + cy = F(x) where F is a polynomial, exponential, sine/cosine, or a product of these, guess the form of yₚ and solve for its coefficients.

Right-hand sideTrial yₚ
pₘ(x) (degree m)Aₘxᵐ + … + A₀
e^(αx)pₘ(x)e^(αx)(Aₘxᵐ + … + A₀)
e^(αx)(Pₘ cos βx + Qₘ sin βx)e^(αx)(A(x)cos βx + B(x)sin βx), with A, B polynomials of degree m

Resonance rule. If α (or α ± iβ in the trigonometric case) is a root of the characteristic equation with multiplicity s (0, 1 or 2), multiply the whole trial function by xˢ.

  • Important detail: for e^(αx)(cos βx, sin βx), multiply by x only if the complex number α + iβ is a root. A real root equal to α is not enough when β ≠ 0.
  • Sums of right-hand sides: find a particular solution for each term and add.
  • Plug yₚ into the equation, collect like terms, and compare coefficients.

5.6 Reduction of Order

Given one nonzero solution y₁ of the homogeneous equation, look for y = u y₁.

  1. Substitute y = uy₁, y′ = u′y₁ + uy₁′, y″ = u″y₁ + 2u′y₁′ + uy₁″.
  2. The terms with u cancel, leaving an equation in u′ and u″ only.
  3. Let z = u′. This is a first-order linear equation for z.
  4. Solve for z, integrate to get u, then y = uy₁.

This also works for the nonhomogeneous equation (the right-hand side stays).

5.7 Variation of Parameters

For P₀y″ + P₁y′ + P₂y = F with known fundamental solutions y₁, y₂, look for yₚ = u₁y₁ + u₂y₂ where

⎧ u₁′y₁ + u₂′y₂ = 0
⎩ u₁′y₁′ + u₂′y₂′ = F/P₀

Solve this 2×2 system (substitution, elimination or Cramer's rule) for u₁′, u₂′, integrate (constants of integration may be dropped), and form yₚ.

  • Use variation of parameters when undetermined coefficients does not apply (for example sec x, tan x, eˣ/x) or when coefficients are not constant.
  • Be careful to divide by P₀: the right side of the second equation is F/P₀.

Common Pitfalls

  • Forgetting the resonance factor x or x².
  • Using e^(αx) in the trial function with the wrong α when the right side has a trigonometric factor.
  • Applying initial conditions to yₕ alone instead of to the full y = yₕ + yₚ.
  • In variation of parameters, forgetting to divide by the leading coefficient.

Practice Problems

Homogeneous

  1. y″ − 4y′ + 13y = 0, y(0) = 2, y′(0) = −1.
  2. y″ + 6y′ + 9y = 0, y(0) = 1, y′(0) = 0.

Undetermined coefficients

  1. y″ − 3y′ − 10y = 6e⁻²ˣ.
  2. y″ + 2y′ + 5y = 3e⁻ˣ cos 2x.
  3. y″ − 2y′ + y = xeˣ.
  4. y″ + 9y = 4x² − 1.
  5. y″ + y = x cos x.
  6. y″ − 5y′ + 6y = e³ˣ + 2x, y(0) = 0, y′(0) = 1.

Reduction of order

  1. x²y″ − 4xy′ + 6y = 0, given y₁ = x², for x > 0.
  2. xy″ − (x+1)y′ + y = 0, given y₁ = eˣ, for x > 0.

Variation of parameters

  1. y″ + y = sec x, on −π/2 < x < π/2.
  2. y″ − 2y′ + y = eˣ/x, for x > 0.
  3. x²y″ − 2y = 3x, given y₁ = x², y₂ = x⁻¹, for x > 0.

Conclusion

For constant coefficients, find the characteristic roots; for a nice right side, guess yₚ (with the resonance rule); otherwise use variation of parameters. When one solution of a variable-coefficient equation is known, reduction of order finds the second.
