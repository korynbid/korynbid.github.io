[ADS-FINAL-PREP] 14. Merge Sort

Oct 24, 2026 · Algorithms & Data Structures · Author: Archiveskk · Source: https://t.me/c/2310214877/1713/1733

Description

Merge Sort is a sorting algorithm based on the Divide and Conquer principle. It divides an array into two halves, recursively sorts these halves, and then merges the sorted subarrays back into a single sorted array.

It is one of the most stable and predictable sorting algorithms with a guaranteed time complexity of O(n log n), making it highly efficient for processing large datasets.

How It Works

  1. Divide: The original array is split into two subarrays. This splitting process continues recursively until subarrays of length 1 are obtained, which are inherently sorted.
  1. Merge: Once the arrays are divided into single-element subarrays, the merging process begins. Two sorted subarrays are combined into a new, fully ordered array.

The algorithm guarantees a execution time of O(n log n) under all conditions, making it more predictable than algorithms like Quick Sort.

Complexity

  • Time Complexity:
  • Best, Average, and Worst Cases: All have the same complexity of O(n log n). This is because the algorithm always divides the array in half and performs a merge operation across all elements of the array.
  • Space Complexity: O(n), as merging requires additional auxiliary memory to store temporary subarrays.

Algorithm Steps

  1. Divide the array into two halves.
  1. Recursively apply Merge Sort to each half.
  1. Merge the sorted halves into a single sorted array.

Code Explanation

  1. merge Method:
  • Accepts two sorted arrays (left and right) and merges them into a single sorted array.
  • Compares elements sequentially, appending the smaller element to the result array. Any remaining elements from either subarray are appended at the end.
  1. mergesort Method:
  • A recursive function that divides the array in half until each subarray reaches a length of 1 (a base sorted state).
  • Performs the merging of sorted subarrays using the merge function.
  1. sort Method:
  • Accepts an array, initializes the merge sort process, and returns the fully sorted array.

Advantages of Merge Sort

  1. Guaranteed Complexity O(n log n): Unlike Quick Sort, which can degrade to O(n²) in the worst case, Merge Sort consistently maintains O(n log n) performance.
  1. Stability: Merge Sort is stable, meaning elements with equal values maintain their original relative order from the input array.
  1. Ideal for Large Datasets: Thanks to its guaranteed time performance and efficiency with large inputs, Merge Sort is widely used in real-world applications, such as processing large files or external database sorting.

Disadvantages of Merge Sort

  1. Space Complexity O(n): The algorithm requires extra memory to store temporary arrays during the merge phase, which can be restrictive when working with extremely large arrays in memory-constrained environments.
  1. Less Efficient for Small Datasets: For smaller arrays, algorithms such as Quick Sort or Insertion Sort can perform faster due to lower constant factor overhead and smaller memory footprints.

Merge Sort Optimizations

  1. Iterative Version: Instead of a recursive call structure, an iterative (bottom-up) approach can be used to avoid stack overflow risks on extremely large datasets. However, it is slightly more complex to implement.
  1. In-Place Merging: Modifying the merge operation to sort in-place avoids allocating temporary auxiliary arrays, minimizing space overhead at the expense of greater algorithmic complexity.

Conclusion

Merge Sort is a stable and efficient sorting algorithm that guarantees O(n log n) runtime performance in all scenarios. It is especially useful when dealing with large volumes of data where predictable execution time and element stability are required. However, its auxiliary space requirement makes it less suited for memory-restricted systems.
