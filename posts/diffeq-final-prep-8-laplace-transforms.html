8. Laplace Transforms

Oct 26, 2026 · DIFFEQ-FINAL-PREP · Differential Equations · Author: Archiveskk · Source: https://t.me/c/2310214877/1867/4793

Description

The Laplace transform turns a differential equation into an algebraic equation:

F(s) = ℒ{f(t)} = ∫₀^∞ e⁻ˢᵗf(t) dt.

Initial conditions are built in, and discontinuous or impulsive forcing is handled naturally.

Derivatives:

ℒ{f′} = sF(s) − f(0),     ℒ{f″} = s²F(s) − sf(0) − f′(0),
ℒ{f⁽ⁿ⁾} = sⁿF − sⁿ⁻¹f(0) − … − f⁽ⁿ⁻¹⁾(0).

8.3 Solving Initial Value Problems

  1. Transform both sides, using the derivative formulas with the given y(0), y′(0).
  2. Solve algebraically for Y(s) = ℒ{y}.
  3. Decompose Y(s) into simple fractions (complete the square for irreducible quadratics).
  4. Invert term by term using the table.

8.4–8.5 Unit Step Function and Piecewise Forcing

  • u_c(t) = 0 for t < c and 1 for t ≥ c.
  • A piecewise function is written as a sum of steps, for example "g₁(t) on [0,c), g₂(t) on [c,∞)" equals g₁(t) + u_c(t) [g₂(t) − g₁(t)].
  • Second shifting theorem: ℒ{u_c(t)f(t−c)} = e⁻ᶜˢF(s). To use it on u_c(t)g(t), first rewrite g(t) as a function of (t−c).

8.6 Convolution

(f*g)(t) = ∫₀ᵗf(t−τ)g(τ) dτ,     ℒ{f*g} = F(s)G(s).

Useful for inverting products such as 1/(s²(s²+1)) when partial fractions is awkward, and for equations with an unspecified forcing function.

8.7 Equations with Impulses

δ(t−c) models a unit impulse at time c. Since ℒ{δ(t−c)} = e⁻ᶜˢ, the solution responds with a sudden jump in y′ of size equal to the impulse at t = c.

Common Pitfalls

  • Forgetting the −y(0) and −y′(0) terms (or their signs).
  • Not completing the square for s² + bs + c with complex roots.
  • Using the second shifting theorem without writing the function in terms of (t−c).
  • Inverting e⁻ᶜˢF(s) and forgetting the factor u_c(t).

Practice Problems

  1. Compute ℒ{t²e⁻³ᵗ} and ℒ{5 sin 4t − 2 cos t}.
  2. Find ℒ⁻¹{(3s+7)/(s² − 2s − 8)}.
  3. Find ℒ⁻¹{e⁻³ˢ/(s²+4)}.
  4. Use convolution to find ℒ⁻¹{1/(s²(s²+1))}.
  5. Solve y″ − 4y′ + 3y = e²ᵗ, y(0) = 1, y′(0) = 0.
  6. Solve y″ + 4y = 8 sin 2t, y(0) = 1, y′(0) = −2.
  7. Solve y″ + 6y′ + 10y = 0, y(0) = 1, y′(0) = 1.
  8. Solve y″ + y′ − 6y = 5, y(0) = 0, y′(0) = 2.
  9. Write the function that is 0 for t<2, equals t−2 for 2 ≤ t<5, and equals 3 for t ≥ 5 using unit step functions, and find its Laplace transform.
  10. Solve y″ + y = f(t), y(0)=0, y′(0)=0, where f(t)=1 for 0 ≤ t<π and f(t) = 0 for t ≥ π.
  11. Solve y″ + 4y = δ(t − π) + 2δ(t−2π), y(0) = 0, y′(0) = 1.

Conclusion

Transform, solve algebraically, decompose, invert. The table of transforms and the shifting, derivative and convolution rules cover nearly every problem in this chapter.
