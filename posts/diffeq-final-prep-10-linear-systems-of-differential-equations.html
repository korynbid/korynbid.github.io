10. Linear Systems of Differential Equations

Oct 26, 2026 · DIFFEQ-FINAL-PREP · Differential Equations · Author: Archiveskk · Source: https://t.me/c/2310214877/1867/4793

Description

A system couples several unknown functions:

𝐲′ = A(t)𝐲 + 𝐟(t),     𝐲 = (y₁,…,yₙ)ᵀ.

Systems arise naturally in models with several interacting quantities, and every higher-order equation can be rewritten as a first-order system.

10.1–10.2 From Equations to Systems

To rewrite y⁽ⁿ⁾ = G(t,y,y′,…,y⁽ⁿ⁻¹⁾) as a system, set y₁ = y, y₂ = y′, …, yₙ = y⁽ⁿ⁻¹⁾. Then y₁′ = y₂, …, yₙ₋₁′ = yₙ, yₙ′ = G(t,y₁,…,yₙ).

10.3 Basic Theory of Homogeneous Systems

  • n solutions 𝐲₁,…,𝐲ₙ of 𝐲′ = A𝐲 form a fundamental set if the matrix Y = [𝐲₁ ⋯ 𝐲ₙ] (a fundamental matrix) has det Y ≠ 0.
  • General solution: 𝐲 = c₁𝐲₁ + … + cₙ𝐲ₙ = Y𝐜.
  • An IVP 𝐲(t₀) = 𝐲₀ has a unique solution when A is continuous.

10.4–10.6 Constant-Coefficient Systems 𝐲′ = A𝐲

Look for 𝐲 = e^(λt)𝛏. Then (A − λI)𝛏 = 𝟎, so λ is an eigenvalue (det(A − λI) = 0) and 𝛏 an eigenvector.

Eigenvalue typeSolutions
Distinct real λᵢe^(λᵢt)𝛏ᵢ
Complex α ± iβ, eigenvector 𝛏 = 𝐚 + i𝐛e^(αt)(𝐚 cos βt − 𝐛 sin βt) and e^(αt)(𝐚 sin βt + 𝐛 cos βt)
Repeated real λ with only one eigenvector 𝛏 (defective)e^(λt)𝛏 and e^(λt)(𝛏 t + 𝛈) with (A − λI)𝛈 = 𝛏

For a repeated eigenvalue with a full set of independent eigenvectors, simply use one exponential solution per eigenvector. In 3×3 problems with a triple defective eigenvalue, a chain of generalized eigenvectors is needed.

10.7 Variation of Parameters for Nonhomogeneous Systems

For 𝐲′ = A𝐲 + 𝐟(t) with a fundamental matrix Y of the homogeneous system:

𝐲ₚ = Y𝐮,     Y𝐮′ = 𝐟 ⟺ 𝐮′ = Y⁻¹𝐟.
  1. Compute det Y.
  2. Solve for 𝐮′ (for 2×2: Cramer's rule, replacing the k-th column of Y by 𝐟 to get uₖ′ = det Yₖ/det Y).
  3. Integrate each uₖ′ (constants may be omitted).
  4. Multiply: 𝐲ₚ = Y𝐮 is a matrix times a vector.
  5. The general solution is 𝐲 = Y𝐜 + 𝐲ₚ.

Common Pitfalls

  • Computing eigenvectors incorrectly (always check (A − λI)𝛏 = 𝟎).
  • Placing eigenvectors in the wrong columns of Y relative to their exponentials.
  • Multiplying in the wrong order (𝐲ₚ = Y𝐮, not 𝐮Y).
  • Dropping arithmetic signs when combining the constants cᵢ with terms of 𝐲ₚ.

Practice Problems

  1. Rewrite y‴ − 2y″ + y′ − 5y = sin t as a first-order system.
  2. Solve 𝐲′ = [[3, 1], [2, 2]]𝐲.
  3. Solve 𝐲′ = [[1, −2], [2, 1]]𝐲 and give real-valued solutions.
  4. Solve 𝐲′ = [[3, −1], [1, 1]]𝐲 (one eigenvalue, defective).
  5. Solve 𝐲′ = [[2, 0, 0], [0, 1, 2], [0, 2, 1]]𝐲.
  6. Solve the IVP 𝐲′ = [[0, 1], [−4, 0]]𝐲, 𝐲(0) = (2, 0)ᵀ.
  7. Verify that Y(t) = [[e³ᵗ, e⁻ᵗ], [e³ᵗ, −e⁻ᵗ]] is a fundamental matrix of 𝐲′ = [[1, 2], [2, 1]]𝐲. Explain using det Y and by checking each column.
  8. Find a particular solution and the general solution of 𝐲′ = [[1, 2], [2, 1]]𝐲 + (3, 2t)ᵀ.
  9. Find a particular solution of 𝐲′ = [[0, 1], [−4, 0]]𝐲 + (eᵗ, 0)ᵀ.
  10. Find a particular solution of 𝐲′ = [[−2, 1], [1, −2]]𝐲 + (2e⁻ᵗ, e⁻ᵗ)ᵀ using variation of parameters.

Conclusion

Systems are solved with linear algebra: eigenvalues and eigenvectors for the homogeneous part, and a fundamental matrix with 𝐮′ = Y⁻¹𝐟 for the forcing. The three eigenvalue cases (real distinct, complex, defective) cover all 2×2 problems.
