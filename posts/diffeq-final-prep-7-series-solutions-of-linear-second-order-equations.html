7. Series Solutions of Linear Second-Order Equations

Oct 26, 2026 · DIFFEQ-FINAL-PREP · Differential Equations · Author: Archiveskk · Source: https://t.me/c/2310214877/1867/4793

Description

When the coefficients are not constant, solutions can often be written as power series. The method depends on whether the expansion point is an ordinary point or a regular singular point.

7.1 Review of Power Series

  • A power series ∑aₙ(x − x₀)ⁿ has a radius of convergence ρ given by the ratio test: ρ = lim |aₙ/aₙ₊₁| (when the limit exists).
  • Inside the radius, series can be added, multiplied, differentiated and integrated term by term.
  • Index shifting: to combine sums, rewrite them so each has the same power xⁿ. For example

``text ∑ₙ₌₂^∞ n(n−1)aₙxⁿ⁻² = ∑ₙ₌₀^∞ (n+2)(n+1)aₙ₊₂xⁿ. ``

  • If ∑aₙxⁿ = 0 on an interval, then every aₙ = 0. This is what lets us extract a recurrence relation.

7.2–7.3 Series Near an Ordinary Point

x₀ is an ordinary point of P₀y″ + P₁y′ + P₂y = 0 if P₀(x₀) ≠ 0 (with Pᵢ analytic).

  1. Put y = ∑ₙ₌₀^∞ aₙ(x−x₀)ⁿ and differentiate.
  2. Substitute and shift indices so all sums have the same power.
  3. Set the coefficient of each power to zero to get a recurrence for aₙ.
  4. a₀ and a₁ stay free; compute the rest. Collect into two independent series y = a₀y₁ + a₁y₂.
  5. The series converges at least on the interval reaching the nearest (possibly complex) singular point.

7.4 Regular Singular Points and Euler Equations

x₀ is a regular singular point if P₀(x₀) = 0 but both

p₀ = lim_(x → x₀) (x−x₀)P₁/P₀,     q₀ = lim_(x → x₀) (x−x₀)²P₂/P₀

exist and are finite. The simplest case is the Euler equation

x²y″ + αxy′ + βy = 0.

Try y = xʳ (for x>0). The indicial equation is r(r−1) + αr + β = 0.

RootsGeneral solution (x>0)
Distinct real r₁, r₂c₁x^(r₁) + c₂x^(r₂)
Double rxʳ(c₁ + c₂ ln x)
Complex λ ± iμx^λ[c₁ cos(μ ln x) + c₂ sin(μ ln x)]

7.5–7.7 The Method of Frobenius

Near a regular singular point x₀ = 0, look for

y = xʳ∑ₙ₌₀^∞ aₙxⁿ,     a₀ ≠ 0.
  1. Substitute; the lowest power of x gives the indicial equation r(r−1) + p₀r + q₀ = 0 with roots r₁ ≥ r₂.
  2. Higher powers give a recurrence for aₙ in terms of r.
  3. Use the largest root first: y₁ = x^(r₁)∑aₙxⁿ always exists.
  4. The second solution depends on the roots:
CaseSecond solution
r₁ − r₂ not an integery₂ = x^(r₂)∑bₙxⁿ
r₁ = r₂y₂ = y₁ ln x + x^(r₁)∑bₙxⁿ
r₁ − r₂ a positive integery₂ = c y₁ ln x + x^(r₂)∑bₙxⁿ (with c possibly 0)

Common Pitfalls

  • Shifting an index incorrectly and misaligning powers of x.
  • Forgetting that the series may start at a later index for some terms.
  • Using xʳ with the smaller root first when roots differ by an integer, which can make the recurrence break down.
  • Applying the Euler solution formulas for x<0 without replacing x by |x|.

Practice Problems

  1. Find the radius of convergence of (a) ∑(n (x−2)ⁿ)/3ⁿ, (b) ∑xⁿ/n!, (c) ∑n! xⁿ.
  2. Rewrite ∑ₙ₌₁^∞ n aₙxⁿ⁻¹ + ∑ₙ₌₀^∞ aₙxⁿ⁺¹ as a single sum of xⁿ terms.
  3. Find the recurrence for y″ − xy′ + 2y = 0 about x = 0, and compute a₂,…,a₆ in terms of a₀, a₁. Identify any polynomial solution.
  4. For (1 + x²)y″ + xy′ − y = 0 about x = 0, find the recurrence relation and the first four terms of each independent series. What lower bound for the radius of convergence do you expect?
  5. Solve the Euler equations for x > 0: (a) x²y″ + 2xy′ − 6y = 0, (b) x²y″ − 3xy′ + 4y = 0, (c) x²y″ + xy′ + 9y = 0.
  6. Solve the IVP x²y″ − 2xy′ + 2y = 0, y(1) = 3, y′(1) = 1.
  7. Classify x = 0 and x = 1 for x(x−1)²y″ + y′ + xy = 0 as ordinary, regular singular or irregular singular.
  8. Find the indicial equation and the first three terms of a Frobenius solution of 3xy″ + y′ − y = 0.
  9. Find the indicial roots of xy″ + 2y′ + xy = 0. What form will the second solution take, and why?

Conclusion

Series methods handle equations that no elementary technique can. At an ordinary point, expand in xⁿ and read off a recurrence; at a regular singular point, use xʳ∑aₙxⁿ and the indicial equation, watching how the two roots relate.
