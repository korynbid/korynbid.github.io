2. First-Order Equations

Oct 26, 2026 · DIFFEQ-FINAL-PREP · Differential Equations · Author: Archiveskk · Source: https://t.me/c/2310214877/1867/4793

Description

A first-order equation can be written y′ = f(x,y) or in differential form M(x,y) dx + N(x,y) dy = 0. Different structures call for different methods, so the first step is always classification.

Classification Checklist

Work through these in order:

  1. Can it be written y′ + P(x)y = f(x)? → linear (2.1).
  2. Can it be written g(y) y′ = h(x)? → separable (2.2).
  3. Is it y′ + P(x)y = f(x)yʳ? → Bernoulli (2.4).
  4. Is it y′ = g(y/x)? → homogeneous (2.4).
  5. Is M_y = Nₓ? → exact (2.5).
  6. If not exact, does an integrating factor depending on one variable exist? (2.6)

2.1 Linear First-Order Equations

Standard form: y′ + P(x)y = f(x), with P, f continuous on an interval (a,b).

  • Integrating factor: μ(x) = e^(∫P(x) dx). Then (μy)′ = μf and

``text y = (1/μ)(∫ μf dx + C). ``

  • Equivalent method (variation of the constant): solve the homogeneous equation y₁′ + P y₁ = 0 for one nonzero y₁, then set y = u y₁. This gives u′ = f/y₁, so u = ∫f/y₁ dx + C.
  • Existence and uniqueness (linear case): if P, f are continuous on (a,b) and x₀ ∈ (a,b), the IVP y(x₀) = y₀ has exactly one solution, and it exists on the whole interval (a,b).

2.2 Separable Equations

If y′ = h(x) g(y), then

∫ dy/(g(y)) = ∫h(x) dx + C.
  • Every root y = c of g(y) = 0 gives a constant solution. These can be lost when dividing, so list them separately.
  • The interval of validity of an IVP solution is the largest interval containing x₀ on which the solution is defined and the steps are legitimate (no division by zero, square root of a negative, and so on).

2.3 Existence and Uniqueness for Nonlinear Equations

Theorem. If f and f_y are continuous on an open rectangle containing (x₀,y₀), then y′ = f(x,y), y(x₀)=y₀ has a unique solution on some (possibly small) interval around x₀.

  • The theorem is local: for nonlinear equations solutions can blow up or leave the region where f is continuous.
  • If f_y fails to be continuous at (x₀,y₀), uniqueness may fail. A classic example is y′ = 3y^(2/3), y(0)=0, which has both y = 0 and y = x³.
  • Two different solution curves of the same equation cannot cross at a point where the theorem applies.

2.4 Transformations into Separable or Linear Equations

Bernoulli equation: y′ + P(x)y = f(x)yʳ, with r ≠ 0, 1.

  • Substitute z = y¹⁻ʳ. Then z′ + (1−r)P z = (1−r)f, which is linear.
  • Equivalent route: solve y₁′ + Py₁ = 0, then put y = u y₁ and obtain the separable equation u′/uʳ = f y₁ʳ⁻¹.
  • For r > 0, y = 0 is also a solution.

Riccati equation: y′ = a(x) + b(x)y + c(x)y².

  • If one solution y₁ is known, substitute y = y₁ + z. The result is a Bernoulli equation in z with r = 2.

Homogeneous equation: y′ = g(y/x).

  • Substitute v = y/x, so y = vx and y′ = v′x + v. Then x v′ = g(v) − v, which is separable.

Lines-intersection type: y′ = (a₁x + b₁y + c₁)/(a₂x + b₂y + c₂).

  • Solve a₁x + b₁y + c₁ = 0, a₂x+b₂y+c₂ = 0 for the intersection point (x₀,y₀), shift X = x − x₀, Y = y − y₀, and the equation becomes homogeneous in X, Y.

2.5 Exact Equations

M dx + N dy = 0 is exact when M_y = Nₓ (on a simply connected region). Then there is F(x,y) with Fₓ = M and F_y = N, and the solutions are F(x,y) = C.

Method:

  1. Check M_y = Nₓ.
  2. Integrate F = ∫M dx + g(y).
  3. Differentiate in y and set equal to N to find g′(y).
  4. Integrate to find g(y) and write F(x,y) = C.

(You may also start from F = ∫N dy + g(x). Choose whichever integral is easier.)

2.6 Integrating Factors

If M_y ≠ Nₓ, look for μ so that μM dx + μN dy = 0 is exact.

  • If (M_y − Nₓ)/N depends only on x: μ(x) = e^(∫ (M_y − Nₓ)/N dx).
  • If (Nₓ − M_y)/M depends only on y: μ(y) = e^(∫ (Nₓ − M_y)/M dy).
  • After multiplying, always re-check that the new M_y = Nₓ before integrating.
  • An integrating factor can also be found by inspection, for example factors of the form xᵃyᵇ.

Common Pitfalls

  • Dividing by g(y) in a separable equation and forgetting the constant solutions.
  • Forgetting the unknown function g(y) (or g(x)) when integrating for F.
  • Using the wrong sign in the integrating-factor formulas. Test the result by re-checking exactness.
  • Giving a solution without its interval of validity, or without applying the initial condition.
  • Substituting z = y¹⁻ʳ but forgetting to transform back to y.

Practice Problems

Linear (2.1)

  1. y′ + (3/x)y = x², y(1) = 2.
  2. y′ + (tan x) y = cos² x, y(0) = 1, on −π/2 < x < π/2.
  3. (x+2) y′ + 3y = 0, y(0) = 4. State the interval of validity.

Separable (2.2)

  1. Find all solutions of y′ = eˣ(y² − 4).
  2. y′ = (3x² + 1)/(2y − 4), y(0) = 1. Solve and find the interval of validity.
  3. P′ = 0.2 P(1 − P/500), P(0) = 50. Find P(t) and lim_(t → ∞) P(t).

Existence and uniqueness (2.3)

  1. For y′ = √(y − x), describe the region where the theorem guarantees a unique solution through (x₀,y₀).
  2. Show that y′ = 3y^(2/3), y(0)=0 has more than one solution. Explain why this does not contradict the theorem.

Transformations (2.4)

  1. x y′ + y = x³y², y(1) = ½.
  2. y′ − 4y = 2x√y.
  3. y′ = y² − 2xy + x² + 1, given the particular solution y₁ = x.
  4. y′ = (x² + y²)/(xy).
  5. y′ = (x + y − 3)/(x − y − 1).

Exact equations (2.5)

  1. (2xy³ + 3x²) dx + (3x²y² + 4y) dy = 0.
  2. (eʸ + y cos x) dx + (xeʸ + sin x) dy = 0.
  3. (2xy + 3) dx + (x² − 4y) dy = 0, y(1) = 2.
  4. Find the constant k for which (kxy² + 4x³) dx + (3x²y + 5) dy = 0 is exact, then solve it.

Integrating factors (2.6)

  1. (3xy + y²) dx + (x² + xy) dy = 0.
  2. y² dx + (xy + 3) dy = 0.

Conclusion

Classification decides the method. Linear → integrating factor. Separable → integrate both sides. Bernoulli, Riccati and homogeneous → substitute. Exact → find a potential F. Not exact → try an integrating factor, and always check the result.
