23. Topological Sort

Oct 24, 2026 · ADS-FINAL-PREP · Algorithms & Data Structures · Author: Archiveskk · Source: https://t.me/c/2310214877/1713/1733

Description

Topological sort is an algorithm for ordering vertices in a Directed Acyclic Graph (DAG). In a topological sort, for every directed edge (u, v), vertex u must precede vertex v in the resulting ordering.

Principle of Operation:

  • Topological sorting is used only for Directed Acyclic Graphs (DAGs)—that is, graphs that contain no cycles.
  • Vertices of the graph are ordered in such a way that for every edge u → v, vertex u appears before vertex v.
  • Topological sorting is useful, for example, in solving scheduling problems, such as ordering tasks with dependencies.

Key Problems Solved by Topological Sort:

  1. Determining the execution order of tasks with dependencies.
  2. Scheduling operations where certain operations must be completed before others.
  3. Resolving dependency calculation problems across various fields (e.g., program compilation).

Topological Sorting Algorithms:

There are several popular algorithms for topological sorting:

  1. Kahn's Algorithm (uses a queue and in-degrees).
  2. Recursive DFS Approach (where vertices are added to the list after completing traversal).

We will consider both methods.

1. Kahn's Algorithm (Using a Queue)

Kahn's algorithm is based on the following principle:

  • For each vertex, count the number of incoming edges (in-degree).
  • Vertices with an in-degree of 0 can be immediately added to the result (they have no dependencies).
  • After adding a vertex to the result, decrement the in-degree of its neighbors. If any neighbor's in-degree becomes 0, add it to the queue.

Algorithm Step-by-Step:

  1. First, compute the in-degree for every vertex.
  2. Place all vertices with an in-degree of 0 into a queue.
  3. Extract a vertex from the queue, add it to the result list, and decrement the in-degree of its neighbors.
  4. When a neighbor's in-degree reaches 0, it is added to the queue.
  5. If all vertices have been added to the result by the end of the algorithm, the graph is acyclic and topological sorting was successful.

Python Implementation (Kahn's Algorithm):

from collections import deque

# Function to perform topological sort using Kahn's algorithm
def topological_sort_kahn(graph):
    # Calculate in-degree for each vertex
    in_degree = {node: 0 for node in graph}  # Initially all in-degrees are 0
    for node in graph:
        for neighbor in graph[node]:
            in_degree[neighbor] += 1  # Increment in-degree for neighbors

    # Add all vertices with 0 in-degree to the queue
    queue = deque([node for node in graph if in_degree[node] == 0])
    result = []  # Final list of topologically sorted vertices

    while queue:
        node = queue.popleft()  # Take a vertex with 0 in-degree
        result.append(node)     # Add it to the result

        # Reduce in-degree for all neighbors
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1  # Decrement neighbor's in-degree
            if in_degree[neighbor] == 0:  # If neighbor's in-degree becomes 0
                queue.append(neighbor)    # Add it to the queue

    # If all vertices are in the result, sorting was successful
    if len(result) == len(graph):
        return result  # Return topologically sorted list
    else:
        return "Cycle detected in graph, topological sort impossible"

# Usage Example:
graph = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': ['D'],
    'D': []
}

print("Topological Sort using Kahn's Algorithm:")
print(topological_sort_kahn(graph))

Output:

Topological Sort using Kahn's Algorithm:
['A', 'B', 'C', 'D']

2. Recursive DFS Approach (Using a Stack / Recursion)

This method uses Depth-First Search (DFS) to guarantee that each vertex is added to the result list after all of its outgoing neighbors have been processed.

Algorithm Step-by-Step:

  1. Perform a recursive depth-first search for each unvisited vertex.
  2. After visiting all neighbors of a vertex, add the vertex itself to the result list.
  3. Since vertices are appended after all their dependencies/neighbors are processed, the resulting list contains vertices in reverse topological order.
  4. Reverse the result list before returning it to obtain the correct ordering.

Python Implementation (DFS Approach):

def topological_sort_dfs(graph):
    visited = set()  # Set to track visited vertices
    result = []      # Final list of topologically sorted vertices

    def dfs(node):
        # If vertex was already visited, return
        if node in visited:
            return
        visited.add(node)

        # Visit all neighbors of the vertex
        for neighbor in graph[node]:
            dfs(neighbor)

        # Add vertex to result after visiting all its neighbors
        result.append(node)

    # Run DFS from every vertex in the graph
    for node in graph:
        if node not in visited:
            dfs(node)

    return result[::-1]  # Reverse the result list, as vertices were added in reverse order

# Usage Example:
graph = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': ['D'],
    'D': []
}

print("Topological Sort using DFS:")
print(topological_sort_dfs(graph))

Output:

Topological Sort using DFS:
['A', 'C', 'B', 'D']

Complexity of Algorithms:

  • Kahn's Algorithm:
  • Time Complexity: O(V + E), where V is the number of vertices and E is the number of edges. We visit each vertex and edge once.
  • Space Complexity: O(V + E) for storing the graph representation, in-degrees, and queue.
  • Recursive DFS Approach:
  • Time Complexity: O(V + E), since every vertex and edge is visited once.
  • Space Complexity: O(V) for the recursion stack and visited set.

Applications of Topological Sort:

  1. Task Scheduling with Dependencies: Topological sort allows ordering tasks so that each task is executed only after all its dependent tasks have finished.
  2. Program Compilation: In compilers, topological sort is used to order modules or source files so that dependencies are compiled first before the main code.
  3. Resolving Query Dependencies: When working with dependent queries in database management systems or workflow engines, topological sorting helps plan execution sequence according to dependencies.

Conclusion

Topological sort is a powerful tool for working with graphs that finds many applications across various domains, ranging from task scheduling and build systems to complex dependency computations.
