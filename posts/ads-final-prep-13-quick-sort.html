[ADS-FINAL-PREP] 13. Quick Sort

Oct 24, 2026 · Algorithms & Data Structures · Author: Archiveskk · Source: https://t.me/c/2310214877/1713/1733

Description

Quick Sort is one of the most popular and efficient sorting algorithms. It utilizes the Divide and Conquer principle.

The algorithm operates by selecting a pivot element from the array and partitioning the array into two sub-arrays: one containing elements smaller than the pivot, and the other containing elements larger than the pivot. The algorithm then recursively sorts these sub-arrays.

Quick Sort works on any array type and features an efficient average time complexity. It was developed by Tony Hoare in 1960.

How It Works

  1. Pivot Selection: A pivot element is selected. Several pivot selection strategies exist, such as picking the first element, last element, a random element, or the median.
  1. Partitioning: The array is partitioned into two sub-arrays:
  2. Elements smaller than the pivot are moved to the left side.
  3. Elements larger than the pivot are moved to the right side.
  1. Recursive Sorting: After partitioning, the algorithm recursively sorts the left and right sub-arrays by repeating the process.

This process continues until sub-arrays reach a size of 0 or 1, at which point the array is fully sorted.

Complexity

  • Average Case Complexity: O(n log n), where n is the number of elements in the array. This is achieved when the array splits into two approximately equal sub-arrays at each step.
  • Worst-Case Complexity: O(n²), which occurs when pivot selection is poor (e.g., repeatedly selecting the absolute minimum or maximum element), causing the array to partition into one element and n - 1 remaining elements.
  • Best-Case Complexity: O(n log n), when the array is consistently divided into two equal sub-arrays.
  • Space Complexity: O(log n) on average (for storing recursive call stacks), and O(n) in the worst case.

Algorithm Steps

  1. Select a pivot element.
  1. Partition the array into two parts based on comparisons with the pivot element.
  1. Recursively sort both parts of the array.
class QuickSort:
    def __init__(self):
        self.array = []

    def partition(self, low, high):
        pivot = self.array[high]
        i = low - 1
        for j in range(low, high):
            if self.array[j] < pivot:
                i += 1
                self.array[i], self.array[j] = self.array[j], self.array[i]
        self.array[i + 1], self.array[high] = self.array[high], self.array[i + 1]
        return i + 1

    def quicksort(self, low, high):
        if low < high:
            pi = self.partition(low, high)
            self.quicksort(low, pi - 1)
            self.quicksort(pi + 1, high)

    def sort(self, arr):
        self.array = arr
        self.quicksort(0, len(arr) - 1)
        return self.array

Code Structure & Logic

  1. partition method:
  2. Selects a pivot element (typically the last element of the active subarray).
  3. Iterates through array elements and rearranges them depending on whether each element is smaller than the pivot.
  4. Returns the final index position where the pivot belongs.
  1. quicksort method:
  2. Recursively sorts the left and right partitions relative to the pivot index returned by partition.
  1. sort method:
  2. Initializes the sorting process on the input array passed as an argument.

Advantages of Quick Sort

  • Average-Case Efficiency O(n log n): Highly efficient compared to simpler quadratic sorting algorithms such as Bubble Sort or Insertion Sort.
  • Fast Practical Execution: Even when compared to other algorithms with equivalent asymptotic complexity, Quick Sort often performs faster due to low overhead and cache-friendly access patterns.
  • Scalability on Large Datasets: Remains one of the most widely used algorithms for real-world production sorting routines.

Disadvantages of Quick Sort

  • Worst-Case O(n²): Poor pivot selection can cause severe performance degradation on ordered or near-ordered inputs.
  • Unstable Sorting: Identical key elements may lose their original relative ordering during swapping.
  • Recursion Overhead: Deep recursion stacks can lead to stack overflow errors on extremely large datasets if not optimized.

Optimizations

  1. Pivot Selection Strategies: To avoid worst-case O(n²) behavior, strategies such as randomized pivot selection or the "median-of-three" (first, middle, and last elements) strategy can be employed.
  1. Tail Recursion Elimination: Transforming one of the recursive calls into an iterative loop reduces stack depth and saves stack memory overhead.

Conclusion

Quick Sort is one of the fastest and most widely adopted sorting algorithms for handling large datasets. It performs efficiently in most practical scenarios; however, proper pivot selection strategies and optimizations should be applied to prevent worst-case performance scenarios.
