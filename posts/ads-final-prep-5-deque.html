[ADS-FINAL-PREP] 5. Deque

Oct 24, 2026 · Algorithms & Data Structures · Author: Archiveskk · Source: https://t.me/c/2310214877/1713/1733

A Deque (Double-Ended Queue) is a generalized data structure that allows adding and removing elements from both the front and the end of the queue. It combines the capabilities of both a stack and a queue.

Core Deque Operations

  1. push_front(x) — Adds element x to the front of the queue.
  1. push_back(x) — Adds element x to the end of the queue.
  1. pop_front() — Removes and returns the element from the front of the queue.
  1. pop_back() — Removes and returns the element from the end of the queue.
  1. front() — Views the first element without removing it.
  1. back() — Views the last element without removing it.
  1. is_empty() — Checks whether the queue is empty.
  1. size() — Returns the number of elements in the queue.

Use Cases

  1. Bidirectional Data Processing: Used in problems where data needs to be processed from both directions.
  1. Stack and Queue Implementation: A deque can serve as a direct replacement for a standard stack or queue.
  1. Sliding Window: Efficiently solves algorithms that find the minimum or maximum value in a subarray of a given size.

Advantages of a Deque

  1. Flexibility: Supports insertions and deletions at both ends.
  1. High Speed: Executes insertion and deletion operations at both ends in O(1) time complexity (when implemented via linked lists or using Python's collections.deque).

Disadvantages of a Deque

  1. Memory Overhead: May consume more memory than required, especially if implemented using dynamic arrays.
  1. Restricted Access: Elements between the first and last cannot be directly accessed.
class Deque:
    def __init__(self):
        self.deque = []

    def push_front(self, item):
        self.deque.insert(0, item)

    def push_back(self, item):
        self.deque.append(item)

    def pop_front(self):
        if not self.is_empty():
            return self.deque.pop(0)
        raise IndexError("Attempt to remove an element from an empty queue")

    def pop_back(self):
        if not self.is_empty():
            return self.deque.pop()
        raise IndexError("Attempt to remove an element from an empty queue")

    def front(self):
        if not self.is_empty():
            return self.deque[0]
        raise IndexError("The queue is empty")

    def back(self):
        if not self.is_empty():
            return self.deque[-1]
        raise IndexError("The queue is empty")

    def is_empty(self):
        return len(self.deque) == 0

    def size(self):
        return len(self.deque)

    def display(self):
        print("Queue contents:", self.deque)
