6. Linked Lists

Oct 24, 2026 · ADS-FINAL-PREP · Algorithms & Data Structures · Author: Archiveskk · Source: https://t.me/c/2310214877/1713/1733

A Linked List is a data structure consisting of nodes (elements), where each node contains data and a pointer (reference) to the next node in the sequence. Linked lists are used to store dynamic datasets and offer flexibility in memory management.

Key Characteristics of Linked Lists

  1. Dynamic Length: The number of elements can change during program execution.
  1. No Fixed Size Limit: A linked list can grow as long as available memory permits.
  1. Non-Contiguous Storage: Elements can be allocated anywhere in memory, linked together via pointers.
  1. Insertion and Deletion: Executed in O(1) time complexity if the pointer to the target node is already known.

Types of Linked Lists

  1. Singly Linked List:

Each node contains data and a pointer to the next node. The last node points to null.

`` [data | next] -> [data | next] -> [data | next] -> null ``

  1. Doubly Linked List:

Each node contains pointers to both the next and the previous nodes.

`` null <- [prev | data | next] <-> [prev | data | next] <-> [prev | data | next] -> null ``

  1. Circular Linked List:

The last node references the first node, forming a closed ring/loop.

Advantages of Linked Lists

  • Efficient Memory Management: The list can grow and shrink dynamically as needed.
  • Fast Insertions and Deletions: Adding or removing nodes requires only updating pointers.
  • No Pre-allocation: Memory does not need to be allocated in advance.

Disadvantages of Linked Lists

  • Linear Access Time: Accessing an element takes O(n) time complexity since the list must be traversed sequentially.
  • Memory Overhead: Storing pointers requires additional memory compared to contiguous arrays.
  • Implementation Complexity: More complex to implement and debug relative to basic arrays.
