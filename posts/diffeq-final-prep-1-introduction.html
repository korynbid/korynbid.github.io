1. Introduction

Oct 26, 2026 · DIFFEQ-FINAL-PREP · Differential Equations · Author: Archiveskk · Source: https://t.me/c/2310214877/1867/4793

Description

A differential equation (DE) is an equation that contains an unknown function together with one or more of its derivatives. If the unknown depends on one variable, the equation is an ordinary differential equation (ODE). The goal is to find the functions that satisfy the equation, or at least to describe how they behave.

Differential equations turn statements about rates of change into mathematics. "The speed of cooling is proportional to the temperature difference" becomes T′ = −k(T − Tₘ).

Key Ideas and Vocabulary

  • Order: the order of the highest derivative that appears.
  • Linear: the unknown and its derivatives appear only to the first power, are not multiplied together, and are not inside other functions. A linear equation of order n has the form

``text aₙ(x)y⁽ⁿ⁾ + … + a₁(x)y′ + a₀(x)y = g(x). `` It is homogeneous if g ≡ 0, otherwise nonhomogeneous.

  • Solution: a function that makes the equation true on an interval. It can be explicit (y = f(x)) or implicit (F(x,y) = C).
  • General solution: a family containing arbitrary constants (as many as the order, for a linear equation). A particular solution has the constants fixed.
  • Singular solution: a solution that is not in the general family (for example, a constant solution lost when dividing by an expression).
  • Initial value problem (IVP): an equation plus conditions at one point, such as y(x₀) = y₀ (and y′(x₀) = y₁ for second order).
  • Direction field: at each point (x,y) draw a short segment with slope f(x,y) for the equation y′ = f(x,y). Solution curves follow the segments. Isoclines are curves f(x,y) = c along which the slope is constant.

Methods

Checking a solution. Differentiate the candidate as many times as the order, substitute, and simplify to 0 = 0 (or to the right-hand side).

Building an equation from a family of curves. If a family has n arbitrary constants, differentiate n times and eliminate the constants.

Sketching a direction field.

  1. Compute f(x,y) on a grid.
  2. Draw a short segment with that slope at each grid point.
  3. Mark isoclines (for example, where the slope is 0) to see where solutions are flat.
  4. Trace a few smooth curves that follow the segments.

Modeling. Name the unknown, translate "rate of change" to a derivative, translate "proportional to" to a constant multiple, and write the initial state as an initial condition.

Common Pitfalls

  • Calling an equation linear because it "looks simple". Terms like y², yy′, sin y or √(y′) make it nonlinear.
  • Forgetting that the number of constants in the general solution matches the order.
  • Writing a solution without the interval on which it is valid.

Practice Problems

  1. State the order of each equation and whether it is linear or nonlinear:

(a) y″ + 3x y′ = sin x (b) (y′)³ + y = x (c) y‴ − y² = 0 (d) y′ + 4y = eˣ

  1. Verify that y = C₁e³ˣ + C₂e⁻ˣ is a solution of y″ − 2y′ − 3y = 0 for all constants C₁, C₂.
  2. Show that x² + y² = C defines solutions of x + y y′ = 0 implicitly. Describe the solution curves geometrically.
  3. Find a first-order equation that has y = Ce⁻²ˣ + 1 as its general solution (eliminate C).
  4. For y′ = y − x: (a) compute the slope at (0,0), (1,0), (0,1) and (2,3); (b) find the isocline of slope 0; (c) sketch the direction field on −2 ≤ x ≤ 2, −2 ≤ y ≤ 2.
  5. A population P grows at a rate proportional to √P, and P(0) = 100. Write the initial value problem.
  6. Find the second-order equation satisfied by y = C₁x + C₂x² on x > 0.

Conclusion

Everything else in the course depends on this vocabulary: identify the order, decide whether the equation is linear, know what kind of solution you are looking for, and always keep initial conditions and intervals in view.
