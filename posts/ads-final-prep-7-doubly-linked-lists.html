[ADS-FINAL-PREP] 7. Doubly-Linked Lists

Oct 24, 2026 · Algorithms & Data Structures · Author: Archiveskk · Source: https://t.me/c/2310214877/1713/1733

The execution time for operations on a doubly-linked list depends on the specific operation being performed:

  1. Adding an element to the end (append):
  • Time: O(1), provided we maintain a pointer to the tail (last element) of the list. We simply append the new node to the end and update the tail pointer.
  • If the list does not maintain a tail pointer, appending to the end requires traversing the entire list, resulting in a time complexity of O(n).
  1. Adding an element to the beginning (prepend):
  • Time: O(1), since inserting a new node at the head only requires updating the head pointer and the next node's previous pointer.
  1. Deleting an element (delete):
  • Time: O(n) in the worst-case scenario when the target element must be searched for first. However, once the node reference is known, the deletion operation takes O(1) time by directly updating the pointers of the preceding and succeeding nodes.
  1. Traversing all elements (display):
  • Time: O(n), as it requires visiting every node in the list sequentially to display or process its content.

Summary

  • Insertion and deletion at the beginning or end of the list execute in O(1) time complexity.
  • Searching and deletion by value require O(n) time complexity.
  • Traversing all elements also requires O(n) time complexity.
class Node:
    def __init__(self, data):
        self.data = data
        self.prev = None
        self.next = None

class DoublyLinkedList:
    def __init__(self):
        self.head = None
        self.tail = None

    def append(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            self.tail = new_node
        else:
            self.tail.next = new_node
            new_node.prev = self.tail
            self.tail = new_node

    def prepend(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            self.tail = new_node
        else:
            new_node.next = self.head
            self.head.prev = new_node
            self.head = new_node

    def delete(self, key):
        current = self.head
        while current:
            if current.data == key:
                if current.prev:
                    current.prev.next = current.next
                if current.next:
                    current.next.prev = current.prev
                if current == self.head:
                    self.head = current.next
                if current == self.tail:
                    self.tail = current.prev
                return
            current = current.next

    def display(self):
        elements = []
        current = self.head
        while current:
            elements.append(current.data)
            current = current.next
        return elements
